      Удаление из памяти

      Удалить эту запись?

      Запись будет удалена из выбранной области. Эта операция не имеет отмены.

      Несохранённые изменения

      В редакторе есть несохранённый текст. Если перейти дальше, изменения будут потеряны.

      Действующие инструкции

      Предпросмотр правил, доступных выбранной области. Выключенные, истёкшие и заменённые инструкции исключены.

      Глобальный блок использует построитель managed prompt. Проектный блок — предпросмотр; передачу проектных правил поддерживает OpenCode. Это не история использования агентом.

      Состояние хранилища

      Доступные возможности

      Notebook, выбор проектов, редактирование метаданных и управление инструкциями.

      RAG, облако, модели и управление клиентами ещё не подключены к панели. Режим хранилища управляется существующим CLI.
