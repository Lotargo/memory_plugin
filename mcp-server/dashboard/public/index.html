                  Состояние хранилища
                  Доступные возможности
                  Notebook, проекты, инструкции, сохранённые источники и Notes, разделы, чанки, редактор Notes/источников, управление связями, сохранённый граф, пробный поиск и удаление знаний.
                  Режим хранения, снимки, облачное подключение и параметры поиска доступны в «Настройках». Управление кэшем, загрузкой моделей и переиндексацией — в разделе «Модели». Настройка клиентов доступна через CLI.
                  
  
    
                  Настройки
                  
    
                  Общие для всех проектов и клиентов на этом компьютере.
                  
    
                  
    
                  
    
                  
      
                  Хранение и облачные снимки
                  
        
                  Рабочая память хранится локально. Облако содержит полные ZIP-снимки; чтение и редактирование памяти не требуют сети.
                  
        
                  
        
                  Включение снимков сохраняет резервную копию. Для прежних облачных режимов выполняется проверка и резервирование обеих копий.
                  
        
                  Расписание снимков
                  Положительное число: 0.5, 24, 168. Расписание выполняется, пока работает панель или клиент памяти.
                  
        
                  
      
                  
      
                  Подключение к облаку
                  
        
                  Сохраняется в существующем зашифрованном хранилище. Проверка подключения запускается отдельно.
                  
        
                  
      
                  
      
                  
      
                  Снимки и восстановление
                  
        
                  
        
                  
        
                    
        
                    Удалить старые снимки
                    Границы периода — 00:00 UTC. Последние, ожидающие и закреплённые снимки защищены.
                    
      
                    
    
                    
                      
  
                    Проверить изменения
                    
  
                    Несохранённые настройки
                    Правки останутся в форме, если продолжить редактирование.
                    
  
    
                    Модели
                    
    
                    Embedding и reranker для поиска и индексации. Выбор модели, размерности, таймера выгрузки и параметров вычислений — в «Настройках».
                    
    
                    
    
                    
    
                    
      
                    
        
                    RAM и память GPU
                    
        
                    
        
                    
        
                    
        
                    RAM процессов плагина
                    
        
                    Память всего процесса (RSS), включая модели и служебные данные. Учтены панель и зарегистрированные клиенты; общие страницы могут пересекаться, поэтому значения не суммируются.
                    
        
                    
      
                    
      
                    Выбранные модели
                    
      
                    Загрузка в память клиента
                    Показаны зарегистрированные процессы. Состояние остальных процессов неизвестно. CPU использует RAM; GPU на Windows — DirectML. Команды требуют подтверждения выбранного клиента.
                    
        
                    
        
                    
      
                    
      
                    Кэш на диске
                    Скачивание проверяет выбранную модель на CPU и затем освобождает память процесса загрузки. Оно не меняет выбор модели для поиска.
                    
        
                    
        
                    «Файлы на месте» означает наличие config, tokenizer и весов; исправность подтверждает только загрузка модели. Для очистки кэша закройте клиенты памяти.
                      
      
                      
      
                      Переиндексация знаний
                      Перестроить векторы всех локальных источников и Notes выбранной embedding-моделью. Новые векторы публикуются вместе после подготовки; Notebook остаётся доступен.
                      
    
                      
    
                      Последняя операция
                      
                        
  
                      Проверить операцию с моделями
                      
  
                      Пробный поиск знаний
                      Контекст — выбранная область; глобальные источники добавляются переключателем в списке знаний. Результат поиска не доказывает передачу или фактическое использование памяти агентом.
                        
  
                        Сохранённый граф знаний
                        Символы адресуются только по имени и могут иметь разные определения. Неопределённые и недоступные концы рёбер не показаны. Структурные рёбра перестраиваются из источника; ручные связи изменяются отдельно.
                          
  
                          Удаление знаний
                            Прежние снимки сохраняют историю. Удалённые данные могут вернуться только при явном восстановлении снимка.
                            
  
    
                            Редактор знаний
                            
    
    
                            Содержимое и параметры индекса
      
                            
      
                            Файлы читаются только из разрешённых каталогов; URL проверяется перед загрузкой.
                            
      
                            Редактор принимает до 2 MiB текста. Для файла или URL текст готовится при явном обновлении.
                            
      
                            
      
                            Embeddings запускают модель. При ошибке сохранённая ревизия остаётся прежней; текстовый вариант удаляет старые векторы. Только изменение тегов или вида Note сохраняет индекс.
                            
    
                            
    
                            
    
                            Текущий сохранённый текст для сравнения с черновиком
                            
    
                            Предпросмотр публикации
                              
    
                                
  
                              Подготовить хранилище знаний
                              Операция создаст и проверит полный локальный ZIP всех проектов, назначит недостающие ID фактам и сохранит отчёт о неоднозначных связях. Облако не используется.
                              Подготовка не завершена. Проверьте локальное хранилище и резервную копию.
                              
  
    
                              Новая связь
                              
    
    
                              
      
                              
        
                              
        
                              
        
                              
        
                              
        
                              
        
                              
        
                              Строки относятся к сохранённому нормализованному тексту. Перед подтверждением проверьте выбранный фрагмент.
                              
      
                              
      
                              Проверка действия
                              
      
                              
      
                              
    
                              
                                
  
    
                              Подготовить устойчивые связи?
                              Будет сохранён полный локальный ZIP-снимок. Факты без ID получат идентификаторы; однозначные связи сохранят принадлежность. Неоднозначные связи останутся в состоянии needs_review.
                              
    
                              Подготовка касается всей локальной памяти. Старые координаты не становятся подтверждёнными автоматически.
